# Amazing Table — Train Brain

Тренажёр внимания, периферийного зрения и скорости чтения на **таблицах Шульте**.
Работает в браузере на телефоне и компьютере, ставится на домашний экран (PWA) и играется офлайн.

## Режимы

| Режим | Задача | Размеры |
|---|---|---|
| Числа | найти числа от 1 до N | 3×3 – 9×9 |
| Обратный счёт | от N до 1 | 3×3 – 9×9 |
| Буквы | по алфавиту (без Ё, Й, Ъ, Ь) | 3×3 – 5×5 |
| Красно-чёрная (таблица Горбова) | чередовать: чёрные по возрастанию, красные по убыванию | 3×3 – 7×7 |

## Возможности

- таймер (стартует с первого нажатия или после отсчёта 3-2-1), счётчик ошибок, прогресс-бар;
- оценка результата звёздами, рекорды по каждому режиму и размеру, история игр;
- настройки: подсказка «что искать», отметка найденных ячеек, перемешивание после каждого верного
  нажатия (сложный режим), точка фокуса в центре, звук, вибрация, светлая/тёмная тема;
- данные хранятся в `localStorage` браузера.

## Запуск

Нужен любой статический сервер (модули ES не работают через `file://`):

```bash
npm start            # python3 -m http.server 8080
# открыть http://localhost:8080
```

Тесты игровой логики (Node 18+):

```bash
npm test
```

## Структура

```
index.html            экраны: меню, игра, результат, статистика, настройки, помощь
css/style.css         стили, светлая и тёмная темы
js/logic.js           чистая логика: генерация таблиц, ходы, рекорды (без DOM)
js/app.js             интерфейс, таймер, звук, сохранение
sw.js, manifest.webmanifest, icon.svg   PWA и офлайн-режим
tests/logic.test.js   тесты логики
```

Для публикации на GitHub Pages достаточно включить Pages для ветки — сборка не нужна.
