# Amazing Table — Train Brain

Тренажёр внимания, периферийного зрения и скорости чтения на **таблицах Шульте**.
Работает в браузере на телефоне и компьютере, ставится на домашний экран (PWA) и играется офлайн.

## Поле

- **Хаос** (по умолчанию) — поле нарезано на клетки разных форм: прямоугольники, полосы, треугольники,
  эллипсы (целые и разрезанные пополам), ромбы, «домики» и веера. Числа разного размера, часть вытянута
  или повёрнута. Уровни: Лёгкий 30, Средний 60, Сложный 90 и Эксперт 90 (числа наклонены под разными
  углами, найденные клетки не тускнеют). Каждая партия — новое поле. Числа, которые вверх ногами читаются
  как другое число на поле (6 и 9, 18 и 81), подчёркнуты.
- **Сетка** — классическая квадратная таблица Шульте.

## Режимы

| Режим | Задача | Размеры |
|---|---|---|
| Числа | найти числа от 1 до N | сетка 3×3 – 9×9, хаос 30/60/90/эксперт |
| Обратный счёт | от N до 1 | сетка 3×3 – 9×9, хаос 30/60/90/эксперт |
| Буквы | по алфавиту (без Ё, Й, Ъ, Ь) | сетка 3×3 – 5×5, хаос 15/25 |
| Красно-чёрная (таблица Горбова) | чередовать: чёрные по возрастанию, красные по убыванию | сетка 3×3 – 7×7, хаос 30/60/90/эксперт |

## Возможности

- таймер с паузой (стартует с первого нажатия или после отсчёта 3-2-1), счётчик ошибок, прогресс-бар;
- оценка результата звёздами, рекорды по каждому режиму и размеру, история игр;
- настройки: подсказка «что искать», отметка найденных ячеек, перемешивание после каждого верного
  нажатия (сложный режим), точка фокуса в центре, звук, вибрация, светлая/тёмная тема;
- данные хранятся в `localStorage` браузера.

## Запуск

Нужен любой статический сервер (модули ES не работают через `file://`):

```bash
npm start            # python3 -m http.server 8080
# открыть http://localhost:8080
```

Тесты игровой логики (Node 18+):

```bash
npm test
```

## Структура

```
index.html            экраны: меню, игра, результат, статистика, настройки, помощь
css/style.css         стили, светлая и тёмная темы
js/logic.js           чистая логика: последовательности, ходы, пауза, рекорды (без DOM)
js/chaos.js           генератор хаотичного поля (чистая геометрия, SVG-пути)
js/app.js             интерфейс, таймер, звук, сохранение
sw.js, manifest.webmanifest, icon.svg   PWA и офлайн-режим
tests/               тесты логики и генератора поля
```

Для публикации на GitHub Pages достаточно включить Pages для ветки — сборка не нужна.
